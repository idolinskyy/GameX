# GameX

Редактор пам'яті локальних процесів на Linux. Знайдіть у грі число (гроші, життя, набої), відсійте зайві адреси, підставте своє значення і за потреби заморозьте його.

**Межі:** без мережевого читу, без приховування процесу, без обходу античиту. Запис у пам'ять — через `process_vm_readv` / `process_vm_writev`. Не для онлайн-матчів.

## Збірка і встановлення

Мова — C++20. Інтерфейс — Qt Widgets. Ядро (`gamex_core`) від Qt не залежить.

### Залежності

```bash
sudo apt install g++ cmake ninja-build
# системний Qt (один із варіантів):
sudo apt install qt6-base-dev
# опційно — мнемоніка в «Хто пише…»:
sudo apt install libcapstone-dev
```

Повідомлення cmake `Capstone not found` — не помилка: без Capstone збірка йде нормально, лише без тексту інструкцій у watchpoint.

### Звичайна збірка (системний Qt)

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/gamex_core_tests   # має надрукувати ok
./build/gamex              # запуск без встановлення
```

### Qt з офіційного інсталера (~/Qt/…)

Якщо Qt стоїть з офіційного інсталера в `~/Qt/…` (наприклад 6.12), вкажіть шлях до нього. Інакше після `install` може підвантажитись системний Qt іншої версії — і буде помилка `version Qt_6.12 not found`:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local" \
  -DGAMEX_QT_ROOT="$HOME/Qt/6.12.0/gcc_64"
cmake --build build
cmake --install build
```

Шлях до бібліотек Qt (`$GAMEX_QT_ROOT/lib`) потрапляє в `RUNPATH` бінарника — окремий `LD_LIBRARY_PATH` не потрібен.

### Встановлення

У домашній каталог (без root; переконайтесь, що `$HOME/.local/bin` у `PATH`):

```bash
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local"
# за потреби додайте -DGAMEX_QT_ROOT=...
cmake --build build
cmake --install build
gamex
```

Встановлюється: `bin/gamex`, ярлик `share/applications/gamex.desktop`, іконки `share/icons/hicolor/…`, документація `share/doc/gamex/` (`LICENSE`, `NOTICE`, `README.md`).

### Видалення

З `$HOME/.local`:

```bash
rm -f "$HOME/.local/bin/gamex" \
  "$HOME/.local/share/applications/gamex.desktop" \
  "$HOME/.local/share/icons/hicolor/"*/apps/gamex.png \
  "$HOME/.local/share/icons/hicolor/scalable/apps/gamex.svg"
rm -rf "$HOME/.local/share/doc/gamex"
```

## Доступ до пам'яті

На Ubuntu з `kernel.yama.ptrace_scope = 1` (так зазвичай і є):

| Як запускаєте GameX  | Що працює                                                                                                                          |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Звичайний користувач | Краще кнопка **Запустити** (гра — дочірній процес). **Обрати процес** до вже відкритої гри ядро часто блокує.                      |
| З правами root       | Кнопка / меню **З правами root** або `sudo -E gamex`. Окреме вікно; зазвичай можна підключатись і до чужих (не дочірніх) процесів. |

Не тримайте GameX під root без потреби. Деякі захищені процеси (snap, `dumpable=0`, `ptrace_scope=3`) можуть лишатись недоступними навіть для root.

Кнопка **З правами root** питає пароль у zenity і передає його в `sudo -S` (не через аргументи командного рядка). На своїй машині цього зазвичай досить; пароль на мить є в пам'яті GameX. Якщо хочете без цього — просто `sudo -E gamex` у терміналі.

## Як користуватись

1. **Запустити** гру (або **Обрати процес**, якщо права дозволяють).
2. Ввести значення з екрана (або вираз `100*10`, або шаблон `DE ?? AD`) → **Шукати**.
3. Змінити параметр у грі → **Відсіяти**. Поки сесія активна, **Шукати** вимкнено (спочатку **Скинути пошук**).
4. **Додати обране** (або подвійне клацання) вниз → правити «Значення → у гру».

Меню дублює кнопки: **Файл**, **Процес**, **Пошук**, **Таблиця**, **Інструменти**, **Довідка** (F1 — повна довідка; також **Про програму** / **Про Qt**).

## Можливості

| Що         | Коротко                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------- |
| Пошук      | Рівність, порівняння, діапазон, невідомий знімок, відсів у фоні + Стоп; сесія Шукати/Відсіяти |
| Типи       | 1–8 байтів (є i24), float, UTF-8, байти; LE/BE                                                |
| Таблиця    | Заморозка (4 режими), групи, F5–F8, файл `.gxt`                                               |
| ASLR       | `module+зсув`, пошук статичних вказівників                                                    |
| Формули    | Вирази в полі пошуку; блок **Знімки M1–M4** + шаблони формул + «Відсіяти формулою»            |
| Структура  | Кілька полів зі зсувами, пошук у фоновому потоці                                              |
| Hex        | Перегляд і запис байтів навколо адреси                                                        |
| Watchpoint | «Хто пише…» через ptrace; RIP — інструкція _після_ запису; TRACECLONE                         |
| Емулятори  | Профілі NES/SNES/GBA/…; при кількох кандидатах RAM — вибір зі списком pathname                |

## Каталоги

```text
src/core   пам'ять, сканер, таблиця, заморозка, watchpoint, профілі емуляторів
src/ui     вікно Qt
tests      перевірки ядра без Qt
cmake/     шаблон номера/часу збірки
```
